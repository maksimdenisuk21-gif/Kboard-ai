Факты отсюда добавляются в каждый разговор — так модель "помнит" о пользователе или контексте между сессиями.

Системный промпт — здесь описывается, кто ИИ, как себя ведёт, какой у него стиль общения и ограничения. Это и есть "обучение" через характер.
Тема оформления
Тёмная — приглушённый графит с оранжевым акцентом. Светлая — тёплый светлый фон, тот же акцент.
Где живёт API-ключ
Ключ Groq больше не вводится на этой странице и не хранится в браузере. Он задан как переменная окружения GROQ_API_KEY в настройках проекта на Vercel и используется только внутри серверной функции /api/chat. Ни один посетитель сайта не может его увидеть — даже через просмотр исходного кода.
Модели
Текст → openai/gpt-oss-120b.
Сообщения с фото → автоматически qwen/qwen3.6-27b (умеет анализировать изображения). Переключение происходит само, вручную выбирать не нужно.
Если нужно сменить ключ
Зайдите в проект на vercel.com → Settings → Environment Variables → обновите GROQ_API_KEY → нажмите Redeploy. Сам ключ никогда не должен появляться в коде сайта или в чатах.
