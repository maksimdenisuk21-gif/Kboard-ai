Ключ API
Хранится на сервере, не в браузере
Ключ Groq задан как переменная окружения GROQ_API_KEY в настройках проекта на Vercel и используется только внутри серверной функции /api/chat. Ни один посетитель сайта не может его увидеть — даже через просмотр исходного кода.
Модели
openai/gpt-oss-120b · авто-переключение на фото
Текст → openai/gpt-oss-120b. Сообщения с фото → автоматически qwen/qwen3.6-27b (умеет анализировать изображения). Переключение происходит само, вручную выбирать не нужно.
Если нужно сменить ключ
Зайдите в проект на vercel.com → Settings → Environment Variables → обновите GROQ_API_KEY → нажмите Redeploy. Сам ключ никогда не должен появляться в коде сайта или в чатах.
